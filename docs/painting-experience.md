# Agent Paint — опыт рисования

## Текущие уроки

14.11.2026: Agent Paint обновлён до 0.5.0 по отчётам этюдов 31–60 и 84–113 (раздел «Версия 0.5» в
`docs/reference.ru.md`).
- Появился необязательный таймлапс, только по просьбе пользователя:
  - `paint_timelapse(action="start")` записывает команды документа;
  - `render` воспроизводит их в MP4, где картина строится мазок за мазком.
- Исправлено то, на что жаловались агенты:
  - `grow`/`shrink` круглые, а `from_layer` умеет жёсткий порог `threshold`;
  - пустой список мазков и вырожденные фигуры пропускаются и не валят пакет;
  - выход за 0..1 на сотые обрезается;
  - `store` принимается внутри `arguments`;
  - ответы больших компактных пакетов больше не раздуваются;
  - имена слоёв уникальны;
  - `merge_down` сливает слой с режимом наложения;
  - заливка ограничивается контуром `points`.
- Новые фильтры: `levels`, `threshold`, `invert`, `hue_saturation`, а у `relief` появился `depth`.

14.11.2026: этюды 84–113 (раздел в конце) снова прошли без ошибок движка. Просьба «одна странная деталь,
видная сразу» в брифе дала самые запоминающиеся места почти в каждой работе. Два новых риска среды:
сетевой обрыв (HTTP 403 до API) убил 19 агентов разом, но их несохранённые документы остались на сервере,
и продолжение через `SendMessage` их доделало; брошенный зациклившийся генератор плана съел 29 ГБ
памяти — процессы убивать только по PID.

09.11.2026: 30 новых стилей (этюды 31–60, раздел в конце) прошли на Agent Paint 0.4.0 без единой ошибки
движка, до 20 агентов одновременно на одном сервере. Сильнее всего работает сценарий, где скрипт
моделирует сам материал (тело вращения, жидкость, петли, плетение, перспектива, карта высот) и отправляет
его одним `actions_file`. Живописные стили с мазком и фактурой по-прежнему выходят гладкими и
«цифровыми». `grow`/`shrink` выделения пока работают квадратным ядром.

08.11.2026: Agent Paint обновлён до 0.3.0 по отчётам 30 стилевых этюдов (раздел README «Версия 0.3»,
подробности ниже). Кисть теперь своя у каждого документа, `layer_id` и имена слоёв работают во всех
рисующих вызовах, большие планы идут файлом (`paint_batch(actions_file=...)`), мазки и полигоны
сглаживаются сплайном (`smooth`), есть пунктир, `paint_pattern` (штриховка, пуантиль, растр, дизеринг),
`relief`, `stamp_visible`, честные жёсткие полигоны, исправленные smudge/акварель и экономная история.
Скилл `agent-paint-reference` переписан под оригинальные работы в любом стиле (revision 2).

06.11.2026: Agent Paint обновлён до 0.2.0 по замечаниям из 19 стилевых этюдов ниже (раздел README

Замечания к движку. Ошибок не было; ниже неудобства и пробелы.

- `paint_selection(grow/shrink)` использует квадратное ядро (`MinFilter`/`MaxFilter`), поэтому
  скруглённые формы при большом радиусе становятся квадратными (45). Репро:
  `{"tool":"paint_selection","arguments":{"action":"ellipse","rectangle":[100,100,300,300]}}`, затем
  `{"tool":"paint_selection","arguments":{"action":"shrink","radius":40}}` и заливка.
- `paint_text` с `layer_id` растрового слоя падает с «Text needs an unlocked text layer». Сообщение не
  подсказывает создать слой `kind="text"` (48, 52, 59).
- Имена новых слоёв: `duplicate`/`stamp_visible` дают «… copy», текстовый слой называется по первому
  символу текста. Приходится переименовывать (42, 51, 53, 60).
- Компактный ответ `paint_batch` всё ещё велик: ~64 тыс. символов на 568 действий. Помогает только
  `results="none"` (42, 54).
- `merge_down` не сливает слои с отсечением или не-normal режимом. Слой с отсечением молча
  привязывается к ближайшему слою без отсечения ниже (34, 58).
- `paint_pattern(rectangle=...)` игнорирует активное выделение и даёт жёсткий край прямоугольника
  (47, 54).
- Эллипс нулевой ширины отклоняет весь пакет с сообщением про углы (41). Пустой `strokes` не
  принимается (43).
- Полигон тоньше 1 px рисуется пунктиром (32). `smooth`-полигон с неравными радиусами даёт выбросы
  (36).
- `paint_snapshot(path)` не перезаписывает файл, а `upscale` меньше 2 молча игнорируется (34, 56).
- Размытие под растушёванным выделением выходит за его край (46). `channel_shift` по слою с
  прозрачными дырами даёт кислотные радужные полосы (52).
- `texture` ≥ .45 заметно снижает покрытие непрозрачных мазков и аэрографа (31, 42). `relief` слаб на
  плавных градиентах (58).
- Агенты просили добавить:
  - заливку «от контура» (shape burst, 38);
  - смещение контура выделения (50);
  - ширину и цвет вдоль штриха (57);
  - коррекции тона и насыщенности, инверсию и умножение на константу (33, 58);
  - шум по маске яркости (46);
  - не-круглые точки `stipple` (49);
  - кисть «пролитой эмали» с рваным краем (36).

Наблюдения:

- Странную деталь агенты поняли и почти везде сделали заметной. Примеры:
  - игла с золотой нитью за край кадра (109);
  - корова не того цвета (101);
  - станция без линий (102);
  - палец аниматора в волне (108);
  - глаз в глубине (103);
  - забранный стикер (100);
  - полная луна в отражении при полумесяце на небе (87).

  Именно эти места запоминаются. Слишком мелкая деталь теряется на 500 px: голубь на стрелке (104),
  карп-призрак (110).
- Как и раньше, лучшие работы моделируют носитель в скрипте. Примеры: каналы молы по полю расстояний,
  поверхность одеяла, карта окружения хрома, зеркальные тона ленты, карта областей картины по номерам.
- Графика, дизайн и ремёсла сильнее живописи с мазком: рококо, энкаустика и тенебризм 31 остаются
  «цифровыми».

Происшествия среды (не движка):

- Сетевой обрыв HTTP 403 («запрос заблокирован до API», VPN или регион) одновременно убил 19 работавших
  агентов. Их несохранённые документы остались открытыми на сервере (ревизии 1–14). Продолжение через
  `SendMessage` с прежним контекстом довело все работы. Два агента ещё не создали документ и начали заново.
  Вывод: при обрыве продолжать, а не перезапускать; сохранять `.apaint` после каждого прохода.
- План-генератор агента 94 зациклился. Его `taskkill /F /IM python.exe` в Git Bash ничего не сделал: MSYS
  превращает `/F` в путь. Брошенный процесс дорос до 29 ГБ, свободной памяти осталось 0,5 ГБ. Координатор
  остановил его по PID, сервер не пострадал. Вывод: завершать процесс только по PID (PowerShell
  `Stop-Process -Id` или `taskkill //PID n //F` в Git Bash); ставить в генераторы предел размера и
  времени.

Замечания к движку. Ошибок не было; самые большие пакеты — ~12 тыс. (109), 4801 (87) и 4241 (103) действий.

  повтор 65).
- `store` внутри `arguments` — то же (96, 110, повтор 66).
- `from_layer` с полупрозрачного слоя даёт мягкое выделение, одна заливка по нему почти не видна (90).

- `smudge` у края холста затягивает прозрачность (86).
- Сглаженный штрих далеко за холстом — «Smoothed stroke is too long», откат пакета. Удаление
  несуществующего слоя откатывает пакет, одинаковые имена дают «ambiguous» (98).
- `upscale` снимка молча не работает при малом `max_side` (105, повтор 34).
- Глиф, которого нет в шрифте, молча пропадает (100).
- Не хватает:
