# Artistic decisions transferred from the reference studies

Open [examples/accepted-face-c-d.png](examples/accepted-face-c-d.png) before relying on this example.
It shows the reference, CSP C and CSP D. The user explicitly preferred D's face. Its finer nose/mouth,
cheek/jaw contour and gaze are the positive result. D still has oversized circular irises and simpler
planes than the source. Preserve attractiveness and expression while judging likeness separately;
do not transplant these exact features to a different person/reference.

| Area | Construct and inspect | Warning that a new method is needed |
| --- | --- | --- |
| Face | Head tilt, eye aperture/tilt, iris ratio, mouth direction, cheek light and jaw | Landmarks match but the expression or attractiveness changes; heavy nose or pale cheek mask |
| Hand | Palm, joint axes, finger overlap, taper and gaps | A tidy outline still has a long thumb, disconnected fingers or no spatial gesture |
| Hair | Connected light/dark groups turning around skull, strand grouping, broken/lost edges | Uniform bright ribbons, U-shaped stripes or texture on an unchanged flat shape |
| Sleeve | Arm axis, bend, support and compression; large light/shadow planes | Isolated leaf-shaped wedges instead of cloth wrapping a bent arm |
| Bodice/skirt | Connected major values, gravity, varied pleat width and depth | Repeated evenly spaced dark/light strips with little depth |
| Background/type | Perspective families, detail scale, hierarchy and text proportions | Flat grid, repetitive windows or lettering that overwhelms the face |

For a consequential correction record:

Source feature → visible mismatch → different construction/mark treatment → inspected result.

Retain an accepted variant as editable layers/version. Compare the alternative at fragment and whole
composition scale. A new face need not look more source-like at the cost of the expression the user
preferred. These are observed failures and one accepted face, not a universally validated painting
method. The first Agent Paint study must establish its own results.
